# 🩺 Doctor Appointment System

A full-stack doctor appointment booking web application where patients can book appointments, doctors can manage schedules, and admins can control the system.

---

## 🚀 Features

- 👨‍⚕️ Doctor appointment booking
- 🔐 User authentication system
- 📅 Schedule management
- 💊 Prescription management
- 🧑‍💼 Admin dashboard
- 📱 Responsive design
- ⚡ Fast and modern UI

---

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other Tools
- Docker
- Docker Compose
